# EducazenKids prototypes

Three clickable prototypes. They use sample data, and there is no backend and no login. They are published on GitHub Pages at https://hamzaaitmansour.github.io/educat-mobile/ (set up 11/10/2026); `index.html` is the entry page and links the three.

| What | Open | For |
|---|---|---|
| Entry page | `index.html` | Anyone with the link: one card per prototype |
| Families website | `web/landing-page.html` (or `web/index.html`) | Parents and collège students: the centre, the app, booking an appointment |
| Staff dashboard | `web/dashboard.html` (« Espace équipe » icon on the website) | Direction and teachers: follow-up, lessons, students, timetable, notifications |
| Student app | `educazenkids-college.html` | The collège app itself, in a phone frame |

## Families website + staff dashboard (`web/`)

Static HTML/CSS/JS, designed with the impeccable skill. The direction contracts are in `../.impeccable/surfaces/`, and product truth is in `../PRODUCT.md`. The fonts (Fredoka, Quicksand, Caveat) are self-hosted in `web/assets/fonts/`, so both pages **work fully offline**.

| File | Role |
|---|---|
| `web/landing-page.html` | The « carnet de liaison »: an open notebook on a purple desk, dated entries (video and the 50 % quiz rule, résumés, emploi du temps, follow-up, parents' words), and the « Vu et signé par les parents » appointment form |
| `web/dashboard.html` | The staff space; views are hash routes `#suivi`, `#lecons`, `#lecons/<id>`, `#lecons/new`, `#eleves`, `#edt`, `#notifs` |
| `web/assets/base.css` | Shared tokens (palette, fonts), plus themed selection, focus rings and scrollbars |
| `web/assets/landing.css`, `landing.js` | Website styles; the live 50 % demo; the signature form |
| `web/assets/dashboard.css`, `dashboard.js` | Dashboard styles; sample data (classes, week timetable, 12 students of 3e B, 11 lessons, alerts, notification history) and all views |
| `web/assets/img/` | Logos and four student-app screens (provenance embedded in each PNG) |

**What works in the dashboard demo:**
- **Alerts:** one-click actions such as « Relancer », « Prévenir la classe » and « Planifier un soutien ». Each sends a notification, updates the timetable where relevant, and can be undone.
- **Role switch:** Direction or Mme Benali.
- **Lesson editor:**
  - type (vidéo + résumé + quiz / résumé + quiz / résumé seul)
  - video upload (reads the real file's duration) or a sample video, and chapters
  - résumé parts and « À retenir »
  - quiz builder with the correct answer and an explanation
  - publish now, schedule or keep as a draft, with validation
  - live phone preview
- **Students:** progress per student and per subject, and the PAP note.
- **Timetable:** edit, add or delete a slot, with room, teacher and class clash warnings.
- **Notifications:** compose with an app preview; the history.

All changes live in memory and reset on reload.

## Student app (`educazenkids-college.html`, source in `src/`)

A single HTML file. Progress (video seconds watched, quiz scores, added timetable slots, settings) is saved in the browser's `localStorage` under `ezk-college-proto-v1`. **Paramètres → Réinitialiser la démo** clears it.

| File | Role |
|---|---|
| `src/page.html` | Page shell: guide column, phone, all-screens view. Placeholders `/*CSS*/`, `/*LOGOS*/`, `/*DATA*/`, `/*APP*/`. |
| `src/app.css` | All styles; tokens on `:root` |
| `src/data.js` | Sample content: subjects, 9 lessons, timetable, contrôles, notifications, study minutes |
| `src/app.js` | State, saved progress, screens, video player, quiz, timetable, sheets, gallery |
| `src/logos.js` | The two logos as embedded WebP, generated by `make-logos.py` from `resources/brand/` |
| `src/build.js` | Writes `src/dist/` (`educazenkids-college.html`, `preview.html`, `_all.js`) |
| `src/test.js` | Node logic checks (must print ALL PASSED) |
| `src/export-extra.js` | Renders one gallery screen per page for PNG exports; moves the page's styles to `<head>` first |

**Commands**, from `prototype/src`:

```
node build.js
node test.js
```

Then copy `dist/preview.html` over `../educazenkids-college.html`.

**Screen exports:** Edge headless, one call per screen, `--window-size=540,844 --force-device-scale-factor=2`, URL `dist/export.html#export-N` (`preview.html` plus `export-extra.js`). Crop each capture to 780×1688 into `resources/screens/v3-college/`. Use 540 px, not 390: headless Edge will not go below about 500 px, and under 520 px the app switches to its full-screen phone layout.

**Rules implemented:**
- The quiz unlocks when **half of the video's seconds have actually been played**; seeking ahead does not count.
- Lesson progress has up to 3 steps: video at 50 %, résumé read, quiz passed at 60 % or more.
- Lesson types: `vqr`, `rq`, `r`.
- The contrôle blanc is a 10-minute timed quiz.
- The demo clock is fixed at Monday 12 October 2026, 09:40.

## Publishing (GitHub Pages)

`../.github/workflows/pages.yml` runs on every push to `main`. It runs `node build.js` and `node test.js` in `src/`, copies this folder without `src/` and `README.md` into the site, and deploys it to https://hamzaaitmansour.github.io/educat-mobile/. `index.html` carries `<meta name="robots" content="noindex">`; the three prototypes do not. `.nojekyll` keeps GitHub from processing the files.
